# ⚖️ Comparación: Deep Learning vs Machine Learning

## 5. Diferencias entre Deep Learning y Machine Learning

Aunque el Deep Learning es un subconjunto del Machine Learning, existen diferencias fundamentales:

| Aspecto | Machine Learning (ML) | Deep Learning (DL) |
|---------|----------------------|-------------------|
| **Definición** | Rama de la IA que permite a las máquinas aprender de los datos sin ser programadas explícitamente | Subconjunto del ML basado en redes neuronales con múltiples capas |
| **Extracción de características** | Requiere **ingeniería de características manual**: los humanos seleccionan qué atributos son relevantes | **Aprende características automáticamente** a partir de los datos brutos |
| **Dependencia de datos** | Funciona bien con conjuntos de datos **pequeños o medianos** | Requiere **grandes volúmenes de datos** para alcanzar un rendimiento óptimo |
| **Requisitos computacionales** | Puede ejecutarse en hardware estándar (CPU) | Requiere **hardware especializado** (GPUs, TPUs) y gran capacidad de cómputo |
| **Interpretabilidad** | Modelos más **interpretables** (árboles de decisión, regresión logística) | Modelos **"caja negra"**: difíciles de interpretar |
| **Arquitectura** | Algoritmos diversos (Random Forest, SVM, regresión lineal) | Redes neuronales profundas con múltiples capas |
| **Tiempo de entrenamiento** | Relativamente **rápido** | **Lento**: puede tomar días o semanas |

### 5.1. Diferencia clave en una frase

> **Machine Learning** aprende con ayuda humana (por ejemplo, seleccionando las características relevantes).  
> **Deep Learning** aprende esas características automáticamente, incluso cuando los datos son imágenes, audio o texto sin estructurar.

## 6. Similitudes entre Deep Learning y Machine Learning

A pesar de sus diferencias, Deep Learning y Machine Learning comparten múltiples aspectos fundamentales:

### 6.1. Objetivo común

Ambos son **subcampos de la Inteligencia Artificial** y comparten la misma meta general: que las máquinas **aprendan de los datos** y realicen tareas sin ser programadas explícitamente para cada caso.

### 6.2. Proceso de aprendizaje

- Ambos **identifican patrones en los datos** para hacer predicciones o tomar decisiones.
- Ambos dependen de **conjuntos de datos** para entrenar algoritmos basados en modelos matemáticos complejos.
- Durante el entrenamiento, ambos **descubren correlaciones** entre las entradas y las salidas conocidas.

### 6.3. Jerarquía

El Deep Learning es **un subconjunto del Machine Learning**, que a su vez es un subconjunto de la Inteligencia Artificial:
Inteligencia Artificial (IA)
Machine Learning (ML)
Deep Learning (DL)
Deep Learning Generativo

### 6.4. Aplicaciones compartidas

Ambas tecnologías se utilizan en dominios similares: detección de fraudes, mantenimiento predictivo, personalización de contenido, reconocimiento de patrones, etc.
